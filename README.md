# МТС Банк — C2C-прототип

Интерактивный прототип мобильного приложения переводов по тестовому заданию. Базовый макет — 402 × 874 px.

## Запуск

Node.js 20+:

```sh
npm start
```

Открыть http://localhost:5173. Зависимости для самого приложения не нужны.

## Реализовано

- Стартовый экран с анимированными руками, картой и сменой сообщений
- Демонстрационный вход по телефону
- Главная с переключаемыми картами, получателями и сворачиваемой историей
- Меню способов перевода
- Авторизованный перевод: выбор и добавление карты, ввод получателя и суммы
- Определение банка по первым восьми цифрам карты через серверный запрос к Binlist; при недоступности — явно обозначенный демонстрационный выбор
- Комиссия, итоговое списание, ошибка нехватки средств и демонстрационное пополнение
- Международный пример RUB → UZS с условным курсом 1 ₽ = 150 UZS и комиссией 0 ₽
- Сохранение получателя при вводе карты, повтор перевода из истории
- Обработка перевода, экран успеха с конфетти и деталями
- Сохранение демонстрационных данных и восстановление страницы в текущей вкладке

Предпросмотр успеха без создания операции: http://localhost:5173/?preview=success

## Важно

Это демонстрация: реальных списаний, авторизации и привязки карт нет. Международный курс условный и не является предложением банка. Расчёт российских переводов иллюстрирует тариф 1,5%, минимум 50 ₽ в другой российский банк и 0 ₽ в МТС Банк; условия реального перевода должен подтверждать банк.

Полные номера карт не сохраняются в браузерном хранилище. Для определения банка внешний сервис получает только первые восемь цифр. При добавлении карты баланс остаётся неизвестным.

Гостевой перевод, сканирование и некоторые дополнительные способы оплаты пока представлены заглушками.

## Структура

- `src/app.js` — маршруты и восстановление страницы
- `src/welcome-screen.js` — старт и демонстрационный вход
- `src/home-screen.js` — главная
- `src/transfers-menu.js` — меню переводов
- `src/authorized-transfer.js` — форма, расчёт, обработка и результат
- `src/data.js` — демонстрационные данные и сохранение
- `src/confetti.js` — анимация успеха
- `src/styles.css` — стили
- `assets/` — изображения, иконки и шрифты
- `src/transfer-screen*.js` — сохранённые предыдущие версии экрана

## Проверки

```sh
npm run check
npm test
```

Браузерные проверки: `npm ci`, `npx playwright install chromium`, затем при запущенном сервере `npm run test:ui`.
Старый набор UI-проверок отражает предыдущую компоновку и требует актуализации под текущие экраны. Отдельные текущие сценарии проверялись в Chromium; Safari и физические устройства отдельно не проверялись.

Шрифты Actay Wide, Inter Tight и Inter включены как используемые проектом ресурсы; при дальнейшем распространении необходимо учитывать их лицензии.
